使用说明 / 快捷键

加载

选择、拖入或 Ctrl+V 粘贴一张 VR180 立体图。默认按中间一刀切分左右两眼；上下叠放的图可切到「上下 TB」。图片只在本机浏览器中解码渲染，不会上传。

OSV 双鱼眼视频

点顶栏「OSV」选文件。工具读取 MP4 里的两条 HEVC 视频轨，用 WebCodecs 解码首帧；拖动时间轴后松手（或点「抽取当前帧」）会从最近的关键帧解到目标帧。Chrome / Edge 且系统支持 HEVC 硬解时可用。

原始视图直接显示鱼眼帧；切到「透视」时使用通用 195° 等距鱼眼近似，首帧会自动估圆半径和圆心，也可以在「鱼眼」参数里手动调。不解析 djmd 标定；若左右眼反了，勾选「交换左右眼」。8K 双路抽帧约 1–3 秒。

显示方式

原始（无形变）：图片 / 视频按源像素比例直接显示，不做透视或鱼眼去畸变；右眼只做 2D 平移 / 旋转 / 缩放。默认使用这个方式。

透视（球面）：把源画面当作球面投影来查看；右眼按下面的旋转采样。适合检查去畸变效果和精确的球面校正参数。

对齐

左眼不动。透视视图下，右眼按下面的旋转采样叠到左眼上；原始视图下换成 2D 相似变换：

透视：R = Ry(yaw) · Rx(pitch) · Rz(roll)

戴红/青眼镜看红蓝模式；没有眼镜就看「差异」模式（越黑越对齐）或「叠加」。把重影调到最小时，三个角度就是右眼相对左眼的校正量。

先调旋转/平移，再用 Zoom 修正左右眼的焦距/视场差：Zoom = 1 不变，>1 放大右眼，<1 缩小右眼（范围 0.9–1.1）。

立体图本身有视差：请让远处的背景对齐；近景残留的重影是正常的，Yaw 尤其应以远景为准。

操作

  • 原始：拖动平移，滚轮缩放；透视：拖动环视，滚轮缩放；双击回中。
  • ← → Yaw，↑ ↓ Pitch，Q E Roll，Z X Zoom；Shift 加大 10 倍步进。
  • 0 视图回中，R 角度/缩放复位，1–5 切换视图。
  • 角度滑杆范围 ±3°，Zoom 范围 0.9–1.1；数值框可直接输入精确数值。

投影

下面的投影设置只在「透视（球面）」视图生效。「等距柱状」按每眼 180°×180°（VR180）或 360°×180°（全景）解释，水平视角可自动判断。「鱼眼」按等距投影解释，可调 FOV、圆半径与圆心，适合未拼接的双鱼眼 SBS 原图。原始视图不使用这些设置，直接把两只眼的源画面叠在一起。

与 Silver Bullet 的关系

本工具只转右眼，所以得到的是两眼之间的相对旋转；Silver Bullet 的 stereo_yaw / pitch / roll 对左右眼各加一半、各减一半，因此填过去时取本角度的一半（小角度近似）。原始视图下的 2D 参数是近似值，写回前建议切到「透视」复核。
