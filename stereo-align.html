使用说明 / 快捷键

加载

图片、MP4 与 OSV 共用一个打开入口：点「打开文件」、拖入，或 Ctrl+V 粘贴一张 VR180 立体图。图片 / MP4 默认按宽高比自动判断：横向切左右 SBS，竖向切上下 TB；判断不对时可手动切换。素材只在本机浏览器中解码渲染，不会上传。

MP4 立体视频

点「打开文件」选 MP4。加载后按画面比例自动选择 SBS / TB，拖动时间轴松手即抽帧；支持 H.264 与浏览器可解码的 HEVC。8K HEVC 通常需要系统 / 显卡硬解，Chrome / Edge 兼容性最好。

若 MP4 内是同一条画面里的左右或上下双画面，按「立体布局」切分；若文件里有两条独立视频轨（OSV 双鱼眼），则会自动按双轨读取，不切分布局。

OSV 双鱼眼视频

同样用「打开文件」选择 .osv，或包含两条 HEVC 视频轨的 MP4；工具会自动识别并切到双轨模式。它读取 MP4 里的两条 HEVC 视频轨，用 WebCodecs 解码首帧；拖动时间轴后松手会从最近的关键帧解到目标帧。Chrome / Edge 且系统支持 HEVC 硬解时可用。

鱼眼帧按源像素直接显示，不做球面去畸变；不解析 djmd 标定；若左右眼反了，勾选「交换左右眼」。8K 双路抽帧约 1–3 秒。

对齐

左眼不动，右眼做 2D 相似变换（平移 / 旋转 / 缩放）叠到左眼上。

戴红/青眼镜看红蓝模式；没有眼镜就看「差异」模式（越黑越对齐）或「叠加」。把重影调到最小时，三个角度就是右眼相对左眼的校正量。

先调旋转/平移，再用 Zoom 修正左右眼的焦距/视场差：Zoom = 1 不变，>1 放大右眼，<1 缩小右眼（范围 0.9–1.1）。

立体图本身有视差：请让远处的背景对齐；近景残留的重影是正常的，Yaw 尤其应以远景为准。

操作

  • 拖动平移，滚轮缩放，双击回中。
  • ← → Yaw，↑ ↓ Pitch，Q E Roll，Z X Zoom；Shift 加大 10 倍步进。
  • 0 视图回中，R 角度/缩放复位，1–5 切换视图。
  • 角度滑杆范围 ±3°，Zoom 范围 0.9–1.1；数值框可直接输入精确数值。
